# Excel Automation Toolkit by Fabio Arias

## 📌 Descripción
Colección de macros VBA para automatizar tareas en Excel, mejorar la productividad y optimizar flujos de trabajo.

## ✨ Características
- Automatización de tareas repetitivas
- Optimización de procesos en Excel
- Código VBA reutilizable

## ⚙️ Requisitos
- Microsoft Excel 2016 o superior
- Habilitar macros

## 🚀 Instalación
1. Descargar el repositorio
2. Abrir Excel
3. Presionar ALT + F11
4. Importar archivo modulos.bas
5. Ejecutar la macro

## 📂 Estructura
- modulos.bas -> Código VBA
- README.md -> Documentación

## 🧠 Uso
Adaptar el código VBA según tus necesidades.
